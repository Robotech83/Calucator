# 🧮 Calculator — Vanilla JavaScript Arithmetic App

A basic, browser-based **calculator application** built with **vanilla JavaScript**, HTML, and CSS.  
This project focuses on **JavaScript logic**, button-driven input handling, and dynamic DOM updates **without frameworks**.

🚧 **Status:** This project is still under construction.

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://robotech83.github.io/Calucator/)

---

## 🎯 Project Purpose

This project was built to:
- Practice **JavaScript fundamentals**
- Implement **button-based input logic**
- Handle arithmetic operations cleanly
- Build a functional UI using **plain JavaScript**

---

## 🧠 What This Project Demonstrates

- Handling user input through button events
- Managing calculation state in JavaScript
- Conditional logic for arithmetic operations
- Dynamic updates to the display using DOM manipulation
- Clean separation of structure (HTML), style (CSS), and logic (JS)
- Framework-free problem solving

---

## 🛠 Technologies Used

- HTML5
- CSS3
- **JavaScript (ES6+)**
